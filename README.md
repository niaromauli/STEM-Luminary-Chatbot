# STEM Luminary: Katherine Johnson AI Chatbot

An AI-powered educational chatbot that simulates conversations with **Katherine Johnson**, the NASA mathematician whose calculations contributed to major U.S. space missions.

The project combines **prompt engineering, Python, and large language models** to create an interactive way to learn about Johnson's life, career, and contributions to STEM.

**Live Demo:** [Hugging Face Space](YOUR-LINK)  
**Model:** `meta-llama/Meta-Llama-3-8B-Instruct`

## Overview

STEM Luminary makes learning about STEM pioneers more interactive through conversation. Users can ask about:

- Education and early career
- Work at NASA
- Contributions to space exploration
- Challenges throughout her career

The chatbot uses **curated biographical information and personality-focused prompt engineering** to guide the model toward responses grounded in Johnson's documented life and achievements.

> **Note:** This is an educational simulation and does not represent Katherine Johnson's actual words or opinions.
